# ICT261 course material

Lecture slides and labs for ICT261 (Mr E Nyirenda, Mulungushi University). The topic summary and the level
mapping are in `../ICT261_TOPICS.md`.

- `originals/`: the slides and PDFs as handed out, with clean names (duplicates removed).
- `text/`: plain-text extracts of each file so Claude Code can search them. Slide text comes out in reading
  order but loses the layout. `lab_gui_lodge_billing_screen.txt` is OCR of a screenshot.

**Not committed to Git.** `originals/` and `text/` are the lecturer's material, and this repo is meant to go on GitHub
as a portfolio piece, so `.gitignore` keeps them local. Only this README and `ICT261_TOPICS.md` are committed.
